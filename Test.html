📡 Como Ligar o ESP32

O ESP32 deve enviar dados via HTTP POST para este servidor. Abaixo o código para o ESP32:

// Código ESP32 — Enviar scan para o site #include <WiFi.h> #include <HTTPClient.h> // Configuração WiFi const char* ssid = "SEU_WIFI"; const char* password = "SUA_SENHA"; const char* serverUrl = "http://SEU_SERVIDOR/api/biometric"; void sendBiometricData(String type, String data) { HTTPClient http; http.begin(serverUrl); http.addHeader("Content-Type", "application/json"); String payload = "{" '"type":"' + type + '",' '"data":"' + data + '",' '"location":"Esquadra PSP Lisboa",' '"timestamp":' + String(millis()) + "}"; int code = http.POST(payload); // code 200 = correspondência encontrada // code 404 = sem correspondência http.end(); }

🔌 Documentação da API

Endpoints disponíveis para integração com o ESP32 e outros sistemas electrónicos.

POST/api/biometric
Recebe dados biométricos do ESP32 (facial ou digital) e compara com a base de dados
Body: { "type": "face|fingerprint", "data": "base64_data", "location": "nome_local", "device_id": "ESP32_001" }
GET/api/missing
Retorna lista de todas as pessoas desaparecidas activas
POST/api/missing
Publica uma nova pessoa desaparecida
Body: { "name": "...", "age": 0, "description": "...", "photo": "base64", "location": "...", "contact": "..." }
POST/api/alert
Envia alerta com localização quando há correspondência
Body: { "missing_id": "...", "found_location": "...", "confidence": 0.95, "contact": "..." }
GET/api/status
Verifica status do servidor e dispositivos ligados
